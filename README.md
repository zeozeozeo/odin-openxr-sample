# Odin OpenXR + [no_gfx_api](https://github.com/LeonardoTemperanza/no_gfx_api) sample

Example of using the [Odin OpenXR bindings](https://github.com/zeozeozeo/odin-openxr) with the [no_gfx_api](https://github.com/LeonardoTemperanza/no_gfx_api) Vulkan abstraction to render a 3D cube in VR.
